Incredibulk

Open a session, copy as much as you need, paste it as one block.

Shortcuts

Click a field and press the combination you want. These are global: they work while any application has focus.

What gets captured

Output format

Tokens you can use
{content}
the fragment itself
{index}
position, starting at 1
{index0}
position, starting at 0
{count}
how many fragments in total
{source}
window it was copied from
{kind}
text, image or files
{time}
when it was captured
{date}
the date it was captured
\n \t
newline and tab

An unknown token is left exactly as you typed it rather than dropped. Image placeholders also take {width} and {height}; file paths take {path}, {name}, {stem}, {ext} and {dir}.

What a paste contains

Rich puts the plain text on the clipboard as well, so editors and terminals receive exactly what they always did. Only applications that ask for formatting see the images.
